# Sprint 1 Review

## Sprint Goal

Build and demonstrate the Oyster frontend UI with working navigation and reusable components.

## Completed Work

- Main public pages were implemented.
- Login and registration UI was created without backend integration.
- User, Diving Center, and Admin dashboard UI pages were created.
- React Router routes and a Not Found page were added.
- Shared Navbar, Footer, Center Card, and Experience Card components were added.
- The frontend was converted to TypeScript.
- The UI Pull Request was reviewed and merged into `develop`.

## Demonstration

| Demonstrated flow | Result |
|---|---|
| Navigate between public pages | Completed |
| Open center, trip, and course details | Completed with mock data |
| Open authentication UI | Completed as UI only |
| Open role dashboard pages | Completed as UI only |
| Production build and lint | Passed |

## Incomplete or Deferred Work

- Real authentication was deferred to Sprint 2.
- Real database and API integration were deferred.
- Booking, payment, and dashboard actions remained mock interactions.

## Feedback

The team agreed to connect the UI to real authentication and API data in the following sprints.
