# Bug Tracking

GitHub Issues are the source of truth for all bugs.

## Issue Link

- All issues: [Repository issues](https://github.com/laradreamer79/Portfolio-Project/issues)
- Open pull requests: [GitHub Pull Requests](https://github.com/laradreamer79/Portfolio-Project/pulls)

## Labels

| Label | Meaning |
|---|---|
| `bug` | Confirmed defect |
| `critical` | Blocks a core flow or release |
| `frontend` | React or browser issue |
| `backend` | Express or API issue |
| `database` | Prisma or PostgreSQL issue |
| `testing` | Test failure or missing coverage |
| `documentation` | Incorrect or missing documentation |

## Priority

| Priority | Definition |
|---|---|
| Critical | Security issue, data loss, or application cannot run |
| High | A Must Have user flow is blocked |
| Medium | Feature works incorrectly but has a workaround |
| Low | Cosmetic or minor usability issue |

## Bug Lifecycle

```text
Open -> Assigned -> In Progress -> Pull Request -> Verified -> Closed
```
