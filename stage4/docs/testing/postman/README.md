# Postman Collection

Export the shared collection here as:

```text
Oyster.postman_collection.json
```

Recommended folders:

```text
Oyster API
├── Health
├── Authentication
├── Users
├── Diving Centers
├── Trips
├── Courses
├── Bookings
├── Payments
├── Reviews
└── Dashboards and Admin
```

Use environment variables:

```text
baseUrl = http://localhost:3000/api
token =
```

Do not commit an exported environment containing real credentials or tokens.
