## Evidence Policy

Testing evidence for this task is text-based. Screenshots are not required. Evidence can be recorded as:

- Postman status codes and response notes.
- Manual test notes.
- Command output summaries.
- API request names and observed results.
- Database confirmation notes from Prisma Studio.

Evidence notes are stored under [evidence](./evidence/README.md).
